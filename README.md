# 3D Goalkeeper Challenge (Work in Progress)

**[Watch Gameplay Demonstration on YouTube](https://youtu.be/htKbIQFXlkM)**

An independently developed 3D football gameplay prototype built in Unity and C#. The project explores goalkeeper mechanics, character movement, animation integration, AI-driven shooting, and physics-based interactions.

## Gameplay Features

- Directional goalkeeper movement and jumping.
- Left and right diving mechanics.
- AI-driven shooting system.
- Character animations and transitions.
- Physics-based ball movement and bouncing.
- Collision-based goalkeeper save detection.
- Goal detection and scoring systems.
- Third-person camera tracking.

## Technical Implementation

| Technology | Purpose |
|---|---|
| Unity 3D | Game engine |
| C# | Gameplay programming |
| Character Controller | Player movement |
| Unity Physics | Ball physics and collision detection |
| Unity Animator | Character animation and transitions |
| Mixamo | Character animations |


## Development Status

This project is currently a work in progress. The core gameplay mechanics have been implemented, with further improvements planned for gameplay responsiveness, animation transitions, and realism.

The gameplay demonstration showcases the current technical implementation rather than a finished product.
